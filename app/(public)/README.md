# Public Route Group

Purpose: public-safe OneGodian App routes.

This route group is for public application pages that do not require privileged operator access.

Allowed examples:

- landing content
- public ecosystem overview
- public documentation
- public-safe tools
- read-only status or manifest views

Do not place Console, ACC, OCP, OEG, workflow administration, audit mutation, adapter management, approvals, internal logs, deployment controls, or kill-switch logic here.
