# onegodian-app — RETIRED

## Repository rule

Existing application code, routes, manifests, configuration, and documentation in this repository are legacy records. They may be consulted when migrating useful components into current specialized properties, but they must not be reactivated as the central OneGodian application.

No new production dependency should target `app.onegodian.com`.
